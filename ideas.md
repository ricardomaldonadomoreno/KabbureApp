# Dirección visual de Kabbure

## Referencia
Kabbure adopta el sistema visual existente de PirateMarket como referencia de continuidad de marca: fondo negro, dorado como acento, Playfair Display para titulares e Inter para interfaz.

## Principios
- Interfaz oscura, sobria y profesional.
- Dorado reservado para acciones principales, rutas destacadas y estados importantes.
- Información de movilidad clara por encima de decoración.
- Mapas y tarjetas como elementos protagonistas.
- Iconografía lineal con Lucide React; no usar emojis.
- Diseño responsive y accesible.

## Tokens
- Negro: `#000000`
- Superficie: `#111111`
- Borde: `#222222`
- Dorado: `#CB9546`
- Dorado claro: `#E5C76B`
- Texto principal: `#FFFFFF`
- Texto secundario: `#888888`
- Éxito / activo: `#06D6A0`
- Peligro: `#E63946`

## Arquitectura de interfaz
La landing pública prioriza el mapa, la búsqueda de rutas cercanas y el estado de vehículos activos. Las acciones de conductor se presentan en un panel emergente deslizable para no sacar al usuario del mapa.

## Marca
El símbolo de Kabbure combina una ruta curva y un punto de ubicación en una silueta plana, con dorado sobre negro.
